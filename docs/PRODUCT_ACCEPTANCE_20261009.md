## 开箱条件与运行模式

- 需要 Python 3.10+。亲自读取源码需要 Git；Node 只用于开发回归。
- 模式 1：查看真实历史演示，或执行新的源码引用核对，不调用模型。
- 模式 2：终端隐藏输入 DashScope Key，使用 qwen3.8-flash 实时提取与语义复核。启动器预算账本限制 10 次请求、100,000 Token、估算 0.2 元；失败不自动重试。
- 自己的报告可导入或粘贴，但自己的仓库仍需先准备本地 Git 和所选版本。程序不执行目标代码。
- 草稿只用于当前标签页刷新恢复；最近任务只属于当前浏览器。结果恢复依赖原输出目录，应导出重要材料。
