## 首次与后续使用

首次新浏览器环境进入时，在同一个欢迎窗口选择“先看一个完整案例”或“核对我的报告”。前者打开明确标注的历史演示结果，不调用模型；后者进入工作台，逐步高亮源码入口、报告区域和模型设置。也可以跳过欢迎。

首页、模型设置、确认页、结果页分别在首次进入时介绍当前页面。每步只显示标题和一两句说明，提供上一步、下一步、跳过；完成或跳过后不自动重复。右上“使用引导”可重新介绍当前页，或重新查看首次入口。模型窗口有独立“查看引导”。不自动填写、点击按钮、切换到未完成的后续页面或发起模型调用。

引导显示柔和遮罩、高亮框和说明卡，切换时短暂平滑过渡；适应窗口尺寸，提供键盘焦点循环、Escape 跳过和减少动态效果设置。完成记录只保存于当前浏览器，不含报告或凭据。清除浏览器存储后会重新出现。

## 模型窗口

默认显示服务商、Key、模型、记住选项、测试连接、保存。通义自动填写接口地址，提供 qwen3.8-flash 预设和自定义模型 ID；其他接口使用自定义兼容服务。模型的可用性仍由账户和接口决定。

API 地址、凭据来源、调用限制、忘记/恢复已保存配置在“高级设置”内。长说明通过可点击、可键盘激活的 ⓘ 展开。测试费用说明仅在点击“测试连接”时出现；再次点击“发送测试”才发起请求。保存本身不联网。

记住配置和忘记凭据是独立操作：不勾选仅影响当前服务，不删除此前保存的配置。高级设置中“忘记已保存的 Key”删除系统保存内容，当前服务仍能使用；“使用已保存配置”切回旧配置。下次启动加载系统保存配置；环境变量仍可能提供凭据，应用不修改系统环境。
