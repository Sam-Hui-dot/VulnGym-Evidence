# 开始使用 0.2.4

## 打开应用

Windows 需要 Python 3.10+；读取源码需要 Git。双击 Source 中的 start-evidence.cmd，选择 1。保留服务终端。Linux/WSL 在 Source 下运行：

```bash
python3 scripts/start_desktop.py --mode demo
```

首次打开只有两个选择：“跟着案例走一遍”或“核对我的报告”。前者在实际工作台从报告、确认条目走到结果；每页只有一条简短提示，通过页面按钮推进。无需 Key，展示已有任务记录，不调用模型。后者直接进入普通工作台，不再逐页弹出遮罩。右上“使用引导”可随时重走完整案例，或主动查看当前页说明。模型设置的说明也只在主动点击“查看引导”后出现。

## 无需 Key 的体验

“跟着案例走一遍”提供完整的三步教学；“直接看演示结果”是快速查看结果的入口。教学期间可选择条目；导出的是完整案例记录。退出教学恢复进入前的任务。刷新会保留教学阶段与勾选范围，原任务草稿不被案例覆盖。若要亲自读取固定源码，在“高级选项”选择“案例引用核对（无需 Key）”，确认后运行；这只核对源码引用位置。

“加载案例报告”会主动加载 FastMCP 教学报告和固定版本；提取与语义复核仍需配置 AI。Starlette 位于“高级选项”→“其他教学案例”。材料使用随包 Git bundle，不自动下载任意仓库。

## 在网页设置 AI

1. 点击右上“模型设置”。
2. 选择“通义 DashScope”，填写自己的 Key，选择模型（演示使用 qwen3.8-flash）。默认 API 地址自动填写，位于“高级设置”。控制台：https://bailian.console.aliyun.com/?tab=model#/api-key 。
3. 其他服务选择“自定义兼容接口”，展开“高级设置”填写 API 基地址，并在模型处选择“自定义模型 ID…”填写对应 ID；必须支持 JSON Schema 结构化输出，不能假定任意模型兼容。基地址通常以 /v1 结尾，不填 /chat/completions。
4. 默认仅本次服务使用。需要下次自动载入时主动勾选“在这台电脑记住 Key”。Windows 使用系统凭据管理器；Linux 需要可用的 Secret Service/secret-tool，没有时仅支持本次使用。
5. 点击“保存”。保存不联网，不自动测试或推理。
6. 如需测试，点击“测试连接”，阅读临时提示后点击“发送测试”。仅发送一条短的 JSON Schema 请求，不发送报告。可以先测试再保存；保存后的状态重置为未验证，保存后再次测试才标记当前配置测试通过。

不勾选记住仅本次使用，不删除旧的已保存配置。若需要删除，在“高级设置”点击“忘记已保存的 Key”；当前服务仍可继续使用。需要切回旧配置时点击“使用已保存配置”。

已有凭据不回显，Key 留空可保留同服务同地址的凭据；更换地址/服务须重新填写。任务运行时不能切换配置。

页面显示实际模型、凭据来源和连接状态。“来自启动环境”表示继承了启动终端的 DASHSCOPE_API_KEY；移除应用配置不修改系统环境变量，下次仍可能继承。

每次桌面服务最多 10 次请求、100000 token 保守预约；测试和失败请求也计入，换模型不重置。费用按服务商账单，不保证账户余额或具体金额。

## 核对自己的报告

1. 点击“连接我的项目”。
2. 粘贴本地 Git 文件夹的完整路径。Windows 使用 D:\Projects\my-project；WSL/Linux 使用 /home/… 或 /mnt/d/…。
3. 选择报告对应的分支、标签或提交；仓库地址可留空，从 origin 读取。
4. 点击“检查并使用”。版本固定为完整 Commit SHA，只读源码，不执行程序或切换分支。
5. 在右侧粘贴全文，或点击“导入报告”选择 UTF-8 .txt/.md（最多 100 KiB）。报告应含文件、行号和引用代码。
6. 提取核查内容，点击候选正文核对报告原句，确认勾选后复核。
7. 查看结论、理由和带行号源码，展开上下文；复制意见、导出 Markdown/HTML/JSON。

换项目/版本后重新提取。项目连接保留本次服务；普通源码 ZIP 不含版本历史。

## 保存和版本范围

报告草稿属于当前标签页，最近任务列表属于当前浏览器，结果文件在本次服务输出目录。Key 不进入浏览器存储、结果或项目配置。重要结果请导出；同一输出目录重启后可恢复已完成任务。

本版只做静态语法检查，没有运行验收，见 DELIVERY_STATUS_20261016_024.md。魔搭是另一个固定只读演示，不提供私人报告或 Key 输入；本地修改不自动部署。
