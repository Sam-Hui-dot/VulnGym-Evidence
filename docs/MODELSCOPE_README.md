# VulnGym Evidence：漏洞报告证据复核智能体

漏洞报告引用了真实代码，对这段代码的解释就一定正确吗？VulnGym Evidence 帮助开发者对照指定版本源码，逐条检查报告中的说法，并保留原句、理由和代码依据。

## 三步看懂演示

1. 点击“查看完整演示”。
2. 选择“参数编码”，查看报告说法和实际源码的矛盾；选择“网络防护”，查看还缺少哪些材料。
3. 点击“展开上下文”阅读源码，或通过“导出报告”保存审阅结果。

这里展示一份基于 FastMCP 公开源码编写的教学报告，以及 2026-10-07 保存的真实 AI 复核任务。查看演示无需 Key，本次访问不会重新调用模型。

## 处理自己的报告

完整本机版支持连接自己的 Git 项目、导入报告、AI 提取核查项、人工确认、源码复核及报告导出。源码包解压后运行 start-evidence.cmd；选择 1 查看演示或核对源码引用，选择 2 在终端配置自己的模型 Key。

这个在线空间只展示固定公开样例，不接收访客的私人报告。工具评价用户确认的具体声明；缺少调用方或部署配置时，会说明还需要什么材料。

项目代码采用 Apache-2.0；FastMCP 教学源码保留 MIT 许可。源码引用一致与报告中的安全解释是否成立分别呈现。
