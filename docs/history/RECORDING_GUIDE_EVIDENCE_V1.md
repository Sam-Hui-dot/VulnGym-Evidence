# 新版录屏准备

按 DEMO_SCRIPT.md 录制 VulnGym Evidence 的网页流程；原 T1 录制指南另存为 RECORDING_GUIDE_T1.md。

## 画面与素材

建议 1080p、约 3 分钟。录屏可用本人熟悉的系统工具或 OBS。先完成一次实际操作，确认本轮代码版本、取证材料、模型配置和输出目录。模型请求需要真实运行，已保存结果用于回放时明确标注。

主画面包含报告输入、候选确认、真实取证阶段、逐条结果、源码摘录、报告与导出。建议另准备三态结果截图。屏幕不显示 Key、账单、私聊或身份材料。

## 交付检查

回看画面和声音是否完整，检查每句功能说明是否与当前实现一致。两赛公开规则的详细时长、文件大小及链接形式仍按最终填报页面确认，旧 T1 的 200 MiB 限制不沿用。

记录视频所用源码版本、样例输入哈希、实际模型和报告目录。保存 MP4 后再生成可访问的视频链接。项目仓库不自动写入大视频或密钥。
