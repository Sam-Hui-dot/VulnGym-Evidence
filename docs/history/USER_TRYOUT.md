# 新人试用：5—10 分钟，无需 Key

适合第一次使用本项目、没有参与开发的人。无需写代码，无需录视频，也不需要告诉试用者样例的参考答案。

## 给试用者的操作单

1. 解压新版源码包，打开 Source，双击 start-evidence.cmd，输入 1 并按回车。
2. 在主页点击“查看完整演示”。选择一项你认为报告需要修改的说法，打开源码，说明你看到的原因。
3. 选择“网络防护”，用自己的话说明为什么现在不能确定，以及还需要什么材料。
4. 点击“导出报告 ▾”，保存 Markdown，打开确认能看到原句、理由和依据。
5. 回到“1 粘贴报告”，点击“运行引用核对（无需 Key）”，再点击“确认并复核 1 项 →”。这次生成一个新任务。
6. 如果你有自己的本地 Git 项目，点击“更换项目”，尝试连接文件夹和版本。只检查连接，不启动 AI 提取。

遇到无法继续的地方，记录所在页面、按钮和提示即可，不要反复点击或修改运行配置。
