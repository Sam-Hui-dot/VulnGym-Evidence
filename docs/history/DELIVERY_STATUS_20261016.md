# 0.2.2 正式使用入口修复

2026-10-16。本版修复首次使用入口、操作辨识和模型配置。0.2.1 冻结目录保留；固定样例与语义判断协议未改写。

## 行为变化

- 新标签页首次打开不预选 FastMCP，不读取某个项目冒充用户选择。用户选择“连接我的项目”或“体验内置案例”后，才显示项目和固定版本。案例明确标为“内置教学案例”。同标签页已有的新版本草稿仍可恢复。
- 连接项目、体验案例、版本详情、导入报告、清空、最近任务、关于、源码详情等采用有边框或背景的操作控件，补充悬停、按下、焦点和禁用表现。高级功能收在“高级选项”，主流程保持一屏布局；低高度/窄屏和展开高级功能可在卡片或弹窗内滚动。
- 网页右上角“模型设置”可选择通义 DashScope 或兼容 Chat Completions 的接口，填写模型 ID、API 基地址和 Key。模型 ID 由用户填写，不自动拉取在线模型列表，不保证任意模型支持结构化输出。
- 配置只在本地服务处理；Key 不进入 sessionStorage/localStorage、结果文件或项目配置。默认仅本次使用；主动选择记住时，Windows 使用 Credential Manager，Linux 使用已安装的 secret-tool / Secret Service。没有可用存储时明确提示，不退回明文保存。
- 保存不联网。测试连接必须在界面勾选费用提示后主动点击，发送短的 JSON Schema 请求，不发送用户报告。页面区分来源（启动环境/系统已保存/仅本次）与连接状态。重启后测试状态重新为未验证。
- 更换服务或 API 地址必须重新填写 Key；不向重定向目的地址转发凭证。服务错误只返回摘要，不向网页回显服务商错误正文或完整 Key。
- 移除会删除当前与系统已保存配置；如果 Key 原来来自系统/终端环境，下一次启动仍可能重新继承，界面会说明。
- 模型修改和测试在提取/排队/复核期间被拒绝；任务捕获固定 Provider。切换模型清除提取缓存，不自动清空历史报告或重跑任务。
- 桌面配置共享本次服务的 10 次 HTTP 请求、100000 token 保守预约上限；测试和失败请求计数，换模型不重置上限。不再把 Flash 价格套用到其他模型，费用以服务商账单为准，不承诺旧版的 0.2 元估算预算适用于新模型。
- 公共固定演示仍禁止全部 POST，不读取本机保存的 Key，不开放访客模型设置；本地修改尚未部署到魔搭。

## 修改与检查范围

本轮仅执行代码/文档/交付目录修改及快速静态语法检查。Python AST 解析和 JavaScript 模块语法检查通过；没有运行测试、构建、服务、浏览器验收、系统凭据读写验证或付费模型请求。历史测试成绩不代表这些新增功能已经运行验收。通义之外的接口需支持 Chat Completions 和 JSON Schema，使用前自行配置并测试。

新增路径：src/vulngym_evidence/model_settings.py；修改 server.py、web/index.html、web/app.js、web/polish.css、scripts/start_desktop.py、版本号及操作文档。
