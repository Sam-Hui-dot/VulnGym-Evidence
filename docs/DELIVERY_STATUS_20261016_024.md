# 0.2.4：连贯案例教学与界面层级

日期：2026-10-16。基于本地 0.2.3 修改；不自动部署魔搭或提交比赛。

## 当前改动

- 首次入口推荐“跟着案例走一遍”，在实际工作台依次走过报告、确认条目、查看结果。提示固定在页面内，每阶段一段短说明，通过真正的页面操作推进。
- 教学使用随包保存的真实任务记录，不调用模型。允许切换条目和勾选范围，结果页仅展示所选条目；导出按钮明确为“导出完整案例”。
- 教学不修改原任务草稿；退出时恢复进入前的材料、结果及任务地址。刷新通过 URL 与 sessionStorage 恢复教学阶段和勾选范围，退出后回到原任务地址并恢复原草稿或结果。
- 普通流程与模型设置取消首次自动弹出分散遮罩；主动点击“只介绍当前页面”或模型“查看引导”仍可使用定位说明。
- 深蓝侧栏标题、浅蓝侧栏、白色报告阅读区和底部操作栏形成分区；按钮增大并增强对比，已连接时“更换项目”降为次要操作。
- 侧栏按内容自然排列，高级选项不再被推到底部。窄屏改为整页滚动，避免把工作区挤成很小的窗格。
- 切回导入页或修改报告时，更新底部提示，避免继续显示结果页的“已复核”提示。
- 录制稿同步新按钮名称，并去掉已取消的自动引导操作。录制正式 AI 流程与免 Key 案例教学保持独立。

## 检查范围

已完成 app.js 的 Node ES module 静态语法检查，并阅读案例 claim_id 对应关系和回放分支代码。未运行回归测试、服务、浏览器操作、截图或付费模型请求，因此视觉效果、实际点击和刷新恢复尚未运行验收。历史测试成绩只适用于其对应版本。

## 使用

先在原终端按 Ctrl+C 结束旧服务，再双击交付目录的“打开新版.cmd”，访问 http://127.0.0.1:8780/ 。原目录保持原样；普通刷新不能把旧服务换成新版。

完整操作见 START_HERE.md；录制稿见 RECORDING_SCRIPT_20261016_024.md。
